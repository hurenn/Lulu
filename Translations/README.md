# メッセージ翻訳の依頼手順

`Message.csv` はゲーム内メッセージ(Stage1シーン・Timeline)の全テキストです。
`Key` 列(内部管理用)以外の `English(en)` 列(と必要なら `Japanese(ja)` 列)を編集してもらいます。

## 1. 翻訳者に依頼する

1. `Translations/Message.csv` を渡す。
2. 編集は **Googleスプレッドシート** を推奨(Excel等のオフラインソフトでも可):
   - Googleドライブで「新規」→「Googleスプレッドシート」→「ファイル」→「インポート」→「アップロード」で `Message.csv` を選択
   - インポート時の設定は「現在のシートを置換」「区切り文字を検出」のままでOK
   - `English(en)` 列を編集してもらう(`Key`/`Id`/`Japanese(ja)` 列は変更しない)
   - `<color=yellow>...</color>` のようなタグは表示制御用なので、タグ自体は残したままタグの中の文言だけ訳してもらう
   - 改行を含むセルはそのまま改行を保持してもらう(セル内で改行 = Shift+Enter)
3. 編集が終わったら「ファイル」→「ダウンロード」→「カンマ区切り値(.csv)」で書き出してもらう。

## 2. 受け取ったCSVを取り込む

1. 受け取ったCSVファイルで `Translations/Message.csv` を上書きする(ファイル名・場所は変えない)。
2. Unityエディタのメニューから **「Lulu > Localization > Message CSVをインポート」** を実行。
3. コンソールに `Message CSVインポート後のキー参照検証: 異常なし` と出ることを確認する。
   - もし `キー参照不整合` というエラーが出た場合は、そのままインポートを確定させず報告すること(過去に1件、参照が別メッセージにすり替わる事故が発生済み)。
4. 実際のテキスト表示はPlay Modeで確認する。

## 3. 最新のテキストをエクスポートし直したいとき

シーン側でメッセージ本文を追加・修正した場合は、Unityメニューの
**「Lulu > Localization > Message CSVをエクスポート」** で `Translations/Message.csv` を最新化してから、翻訳者に再度渡す。
